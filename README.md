Snooze Button Roast

One line roasting an alarm clock that rings at 6 AM on a Saturday:

> 6 AM Saturday, my alarm clock's a wedding DJ asking an empty room to make some noise.

## Run it

```sh
node main.ts   # writes /output/entry.txt (Node 22.18+)
```

The entrypoint writes a single UTF-8 text to `/output/entry.txt`, as the
competition's program protocol requires. It has no dependencies and no network
or secret access.
